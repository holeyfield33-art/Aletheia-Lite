# Changelog

## 1.0.0 - 2026-09-03

- Local pre-execution enforcement through Scout -> Nitpicker -> Judge.
- ALLOW, OBSERVE, and BLOCK decisions with zero-standing-privilege and
  confused-deputy checks.
- Ed25519-signed policy manifests and signed, hash-chained execution receipts.
- Token velocity and circuit-breaker guards.
- Sequence-aware SPRT swarm detection.
- Local authenticated dashboard with ALLOW events included.
- Python API and `aletheia-lite` CLI, including a deterministic four-scene demo.

Claims in this release are limited to behavior covered by the test suite and
release verification tooling.
